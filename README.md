## 📋 Overview

The site provides an accessible, mobile-responsive portal for students to:
- Discover upcoming hackathons, AI workshops, and entrepreneurship summits.
- Inspect venue locations, event dates, and registration details via interactive modals.
- Submit inquiries and register for upcoming campus happenings.
